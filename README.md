# Gym Management System (C# Desktop Application)

> A desktop application engineered in C# to streamline member management and subscription tracking workflows for fitness centers.

---

## Overview
This project is a functional desktop application designed and developed using Object-Oriented Programming (OOP) principles in C#. It focuses on simplifying core administrative workflows, including member registration and subscription tracking.

---

## Key Technical Features
- **Member Management:** Dedicated workflows to register, update, and manage member profiles.
- **Subscription Tracking:** Automated monitoring of member status and subscription records.
- **Object-Oriented Architecture:** Designed using OOP principles for modularity, readability, and clean code organization.

---

## Tech Stack & Development Environment
- **Programming Language:** C#
- **Development Paradigm:** Object-Oriented Programming (OOP)
- **Development Tools:** Visual Studio, Git, GitHub
